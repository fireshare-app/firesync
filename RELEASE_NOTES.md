## New

- Catches up on clips recorded while Firesync was closed or a folder's drive was disconnected
- Actions for each file in Activity: retry, try now, stop, skip, upload anyway, copy link, show in folder
- Search and a folder filter in Activity
- Your last three uploads in the tray, one click to copy a link, plus an option to copy each new link automatically
- An upload speed limit, and a choice to slow down or pause uploads while a game has the screen (Windows only)
- Title templates for uploads, such as {game} — {date}
- Tags for each folder, picked from your Fireshare (needs a Fireshare that offers tags to upload tokens)
- Network folders, such as a NAS or a shared drive, are checked every 15 seconds instead of watched
- Troubleshooting in Settings: copy a diagnostics report for a bug report, or open the log files

## Improved

- A free upload slot starts the next file straight away
- The Game and Fireshare folder lists refresh from Fireshare whenever you open them
- Folder settings warn when a folder's game has been renamed or deleted in Fireshare
- Turning on Watch subfolders works without a restart
- A folder whose drive is disconnected says so, and picks up again when the drive is back

## Fixed

- Clips sorted by game no longer land in your default folder when Firesync starts before your network is up

## Good to know

- The first time 1.1.0 checks each folder, files it has never seen are held in that folder's backlog for you to review, not uploaded
- Files that arrive while a folder is paused also wait for review
